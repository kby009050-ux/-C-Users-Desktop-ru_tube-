# 🎬 ru_tube Studio - AI 유튜브 쇼츠 & 롱폼 자동화 제작기

대본(스크립트)만 입력하면 **고품질 한국어 AI 성우 음성(TTS) + 동적 자막 + 배경 영상**이 결합된 완성형 MP4 비디오를 원클릭으로 자동 렌더링해 주는 유튜브 자동화 스튜디오입니다.

---

## ✨ 핵심 기능
- 📱 **쇼츠 (Shorts) 자동 제작**: 9:16 비율(1080x1920)로 세로 영상 최적화 렌더링
- 🎬 **일반 롱폼 (Long-form) 자동 제작**: 16:9 비율(1920x1080)로 일반 유튜브 영상 렌더링
- 🎙️ **자연스러운 한국어 AI 성우 (Edge-TTS)**: 선희, 인준, 현수, 지완 등 고음질 AI 보이스 지원
- ✍️ **스마트 자막 자동 생성**: 문장별 음성 길이에 맞춰 가독성 높은 볼드 자막바 자동 합성
- 🎨 **감성 배경 무드**: 퍼플 네온, 딥 블루, 골드 다크 등 영상 분위기에 맞는 동적 배경
- 📥 **원클릭 다운로드 & 보관함**: 생성 즉시 웹 플레이어에서 재생 및 다운로드 가능

---

## 🚀 빠른 시작 가이드 (Windows)

바탕화면의 **`ru_tube 실행`** 바로가기(또는 폴더 내 `run.bat`)를 더블클릭하면 1초 만에 브라우저가 열리며 바로 사용하실 수 있습니다!

---

## 🛠️ 기술 스택
- **Engine**: FFmpeg, MoviePy, Pillow
- **AI TTS**: Edge-TTS (Microsoft Azure 기반 고음질 한국어 음성)
- **Backend**: Python 3.12, Flask
- **Frontend**: Modern Responsive HTML5 / CSS3 / Vanilla JS
